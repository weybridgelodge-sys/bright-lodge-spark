- Treasurer posting periods: any non-locked treasurer_periods row is postable; screens use usePostingPeriod/PeriodPicker (default = period containing entry date) — never a single global 'open' period. Why: backfills and late postings were misfiled.
- Members portal routing: /members/* must always resolve to something. The portal index (/members) IS the dashboard; /members/dashboard redirects there because transactional emails link to it, and a * catch-all inside MembersRoutes redirects anything else to the index. Why: an unmatched path rendered a blank navy page with no route, so emailed CTAs dead-ended.
- Auth bootstrap: AuthProvider must always settle its loading flag — getSession() has a .catch() and an 8s guard timer, and every loadProfileAndRole call site swallows rejections. Why: ProtectedRoute renders a full-screen loader while loading is true, so a promise that rejects or never settles hangs the whole portal.

- Journal document numbers: journal_entries.entry_number is assigned only by the tg_journal_entry_number trigger (sequence) and is immutable; display via formatEntryNumber (JE-000123). document_number stays free-text user reference. Why: every posting path, including edge functions, gets a permanent number without code changes.
- Bank split matching: bank_statement_transactions.matched_journal_line_id stays the primary link; extra ledger lines go in bank_statement_match_lines, written only via link_bank_row_to_lines / unlink_bank_row RPCs; "taken" checks use both, across all statements. Why: one bank payment can settle several ledger lines without breaking existing matches.
- Treasurer report period ranges live as pure helpers in src/lib/treasurer/reportPeriods.ts; account drill-downs use the shared AccountDrilldown. Why: one tested source keeps month/YTD/year figures reconciling and drill totals agreeing with reports.
- Year-end close: treasurer_periods.period_type='closing' (one per masonic_year) holds the single year_close journal, posted only via post_year_close RPC (dated 1 Oct next year, auto-locks). Month pickers/calendars exclude closing periods; I&E/Trial Balance year movement excludes closing-period entries; Balance Sheet puts them in General Fund b/f. Why: the close only sets next year's opening fund without distorting live reports.

- App shell: AppErrorBoundary wraps all routes (and the members portal); Suspense fallbacks use PageLoader, never null; chunk-load reloads add a ?_r= cache-buster and may retry after 60s. Why: a render crash or stale edge-cached HTML otherwise left a blank navy screen after magic-link sign-in.
- Magic-link errors (#error=/error_code=) are captured in main.tsx into sessionStorage "auth-link-error" and shown once on the Login page. Why: expired/pre-scanned links otherwise bounced silently to sign-in.
- Year-end audit sign-off: treasurer_year_approvals status changes only via submit_year_for_audit RPC (server-computed snapshot, new round each time) and the signoff insert trigger (query→'query', both confirmed→'approved'); signoffs are insert-only; post_year_close requires 'approved'. Why: auditors' certification must be tamper-proof and each round auditable.
- Year-end accounts pack: content chosen by selectPackSource (approved → approved round frozen figures_snapshot + treasurer_remarks; else live year_live_snapshot + draft remarks, marked DRAFT); certified copy stored once at lodge-docs/year-end-accounts/ via record_certified_pack (never overwritten). Why: the pack must always match what the auditors certified.
- Annual accounts distribution: certified packs go to members as a second branded link (/accounts/:year?k=<approval id> → accounts-link, 7-day signed URL) in the summons email, only on a summons with no sent_at; record_accounts_sent (service role, write-once) stamps treasurer_year_approvals.accounts_sent_at/with_summons_id. Why: mirrors summons-link and the per-recipient idempotency key would silently drop accounts on an already-sent summons.
- Subscription split: each member's subscription splits via splitSubscription (4000 remainder, 3100 per pot tagged fund_code, 2200 Relief Chest share from subscription_settings.relief_chest_pence; under-25 at 1 Oct halves shares). The annual charge is posted only by post_subscription_accrual (Treasurer-triggered, one per year); Direct Receipt in-year payments and prepayment clears never re-split. Why: the split happens once, at income recognition.
- Treasurer/Secretary subscription exemption uses the most recent appointment on or before the year (subscription_exempt_member_ids, dues_calculate_amount). Why: officers can serve years without a fresh appointment row.
