- Treasurer posting periods: any non-locked treasurer_periods row is postable; screens use usePostingPeriod/PeriodPicker (default = period containing entry date) — never a single global 'open' period. Why: backfills and late postings were misfiled.
- Members portal routing: /members/* must always resolve to something. The portal index (/members) IS the dashboard; /members/dashboard redirects there because transactional emails link to it, and a * catch-all inside MembersRoutes redirects anything else to the index. Why: an unmatched path rendered a blank navy page with no route, so emailed CTAs dead-ended.
- Auth bootstrap: AuthProvider must always settle its loading flag — getSession() has a .catch() and an 8s guard timer, and every loadProfileAndRole call site swallows rejections. Why: ProtectedRoute renders a full-screen loader while loading is true, so a promise that rejects or never settles hangs the whole portal.

- Journal document numbers: journal_entries.entry_number is assigned only by the tg_journal_entry_number trigger (sequence) and is immutable; display via formatEntryNumber (JE-000123). document_number stays free-text user reference. Why: every posting path, including edge functions, gets a permanent number without code changes.
